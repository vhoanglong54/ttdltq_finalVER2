# Notebooks tái tạo phân tích

- `01_data_audit.ipynb` — T05: cấu trúc, chất lượng, khóa, missing, outlier.
- `02_cleaning.ipynb` — T06–T07: giải thích cleaning, merge, calculated fields và kiểm tra.
- `03_eda.ipynb` — chạy lại EDA, hiển thị sáu hình tĩnh, H01–H10 và sáu insight.

Mã tái tạo chính đặt trong `src/`; notebook là lớp trình bày và gọi lại script chuẩn để tránh hai phiên bản công thức. Output lớn không nhúng trực tiếp vào notebook.
